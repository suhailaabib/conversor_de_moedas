# Praticando Java: Challenge conversor de moedas!

## Objetivo:

* Apresentar a conversão da moeda de um país para outra moeda de outro país.

## Funcionalidades:

*  Solicitar ao usuário que escolha uma opção do sistema.
*  Digitar o valor que deseja converter.
*  E o resultado será mostrado.
